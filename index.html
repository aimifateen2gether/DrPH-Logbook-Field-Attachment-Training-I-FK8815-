How to use this dashboard

  1. Edit logbook.csv whenever you add an activity.
  2. Use one row per mapped competency if a single activity demonstrates multiple competencies.
  3. Keep identifiable patient/respondent data and confidential internal documents off GitHub.
  4. Use the dashboard for supervision meetings, but retain the official UKM logbook for formal comments, signatures and assessment.
